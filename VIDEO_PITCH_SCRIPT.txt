SEGMENT 3: THE SOLUTION — ARCHITECTURE (1:15 – 2:00)
================================================================================

[SHOW: Architecture diagram slide OR Streamlit app]

"We built an 11-agent AI pipeline. Not a single model — eleven
specialized agents that each handle one aspect of valuation.

Here's how it works:

First, the Input Normalizer geocodes the address.

Then four agents run in parallel — Location Intelligence queries
OpenStreetMap for every metro station, school, hospital, and mall
within 3 kilometers. Property Characteristics calculates age
depreciation. Market Dynamics assesses supply and demand. And Legal
checks ownership clarity.

These feed into the Valuation Agent — which uses a completely transparent
formula. Circle rate times area times six adjustment factors. No LLM,
no black box. Pure math.

Then the Liquidity Agent computes the Resale Potential Index.

The Fraud Agent runs 7 cross-checks — including an LLM that catches
subtle anomalies like a 4BHK claimed in a 400 square foot apartment.

And finally, the Synthesizer agent uses Claude to generate a human-
readable explanation that a credit officer can actually understand."

RECORDING GUIDE — HOW TO MAKE THE VIDEO
================================================================================

OPTION 1: SCREEN RECORDING + VOICEOVER (Easiest, 30 min to make)
  Tool: QuickTime (Mac) → File → New Screen Recording
  1. Open Streamlit app in Chrome
  2. Start recording
  3. Read the script while clicking through the demo
  4. Trim in iMovie (free on Mac)

OPTION 2: LOOM (Professional, 15 min to make)
  Tool: loom.com (free plan = 5 min videos)
  1. Install Loom Chrome extension
  2. Record screen + camera (picture-in-picture)
  3. Auto-uploads with shareable link

OPTION 3: OBS STUDIO + CANVA SLIDES (Most polished, 1-2 hours)
  1. Make slides in Canva/Gamma (use the PPT content file)
  2. Record in OBS Studio (free) with scene switching:
     Scene 1: Slide deck (for problem/architecture slides)
     Scene 2: Streamlit demo (for live demo segment)
     Scene 3: Camera (for intro/outro)
  3. Edit in DaVinci Resolve (free) or iMovie

OPTION 4: PROFESSIONAL ANIMATION (Most impressive, 3-4 hours)
  Tool: Remotion (remotion.dev) — React-based video framework
  OR: Motion Canvas (motioncanvas.io) — code-driven animation
  OR: Manim (manimce.org) — Python math animation (used by 3Blue1Brown)
  1. Animate the agent DAG flowing
  2. Animate numbers calculating step by step
  3. Animate the Bloomberg-style output card appearing
  4. Export as MP4


================================================================================
TIPS FOR AN IMPRESSIVE VIDEO
================================================================================

1. START WITH A STORY, NOT TECH
   "A borrower walks in..." not "We built an 11-agent system..."

2. SHOW THE DEMO EARLY
   Don't make them wait 3 minutes for the demo. Show it by minute 2.

3. PAUSE ON IMPRESSIVE NUMBERS
   When you show "24-53 days to sell" or "7 fraud checks" — pause.
   Let it sink in.

4. COMPARE TO STATUS QUO
   "Today this takes 3-7 days. We do it in 5 seconds."

5. END WITH THE POONAWALLA CONNECTION
   Show their actual LAP scenarios. Show it works for THEIR business.

6. KEEP UNDER 5 MINUTES
   Attention drops after 5 min. 4:30 is perfect.
